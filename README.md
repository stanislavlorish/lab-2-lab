Программа должна считать данные (используя массивы строк и чисел), объединить одинаковые наименования, просуммировав их количество, и вывести в output.txt чистую сводную ведомость без дубликатов (например: Дерево: 25 шт., Камень: 13 шт., Семена: 4 шт.).
